# Ice for Android

Plex player with true direct play (VLC engine, every format), Continue Watching, a load-ahead
cache on the phone's storage that rides out dead zones, skip intro/credits, up next, per-device
audio delay and a mini player.

Install: open https://github.com/icemangonewrong/Ice-Android/releases/latest/download/Ice.apk on the
phone and allow installing from your browser.

The APK is signed with the key in `signing/` so each new build installs over the last one.
